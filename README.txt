P.K.E. METER — simplified V3

Extract this folder, open it in VS Code, then open index.html with Live Server.

The meter starts automatically. Scanner readings are randomized visual effects, not actual paranormal detection. Red-zone readings now occur a little more often, while green and yellow remain the more common states. TASE is a synthesized sound/visual effect only; it produces no electrical discharge.

Browser audio requires a user gesture. The scanner display starts automatically; the continuous buzz begins after the first tap/click anywhere in the app. There is no start button.
